# Hydrocarbon Quest Sound Licenses

No external sound files are currently bundled for this simulation.

Chemlab uses a procedural Web Audio fallback for atom clicks, hover ticks, wrong-answer feedback, chain-completion chimes, name-forge sounds, and badge/level rewards.

If local audio files are added later, use CC0 or clearly permitted open-source/Creative Commons sounds only, and document each file here with its source and license.
