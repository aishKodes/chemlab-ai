# Chemlab Content Quality Standard

Every Chemlab resource must be scientifically accurate, NCERT-aligned, age-appropriate, visually clear, mobile usable, source-referenced, and reviewed before publishing.

## Resource Quality

- Use original Chemlab explanations.
- Keep one clear learning goal per screen.
- Avoid generic copy and vague praise.
- Show the idea, one example, and one common mistake.
- Keep public copy student-facing.
- Do not expose internal technology language on student pages.
- Add source reference and review status.
- Attach Chem-Shastri context notes.
- Attach analytics keys for views, mistakes, hints, and completion where relevant.

## Simulation Quality

Every simulation should include:

- objective
- meaningful interaction
- immediate feedback
- summary
- linked memory cards
- linked quick drill
- Chem-Shastri context
- analytics events

Simulation screens should avoid clutter, avoid text blocking visuals, and make chemistry labels accurate. Interactions must teach the concept rather than decorate the page.

## Memory Card Quality

- One concept per card.
- Front side should be short.
- Back side should explain why.
- Include mistake cards.
- Add difficulty and mistake key where useful.
- Review scheduling should work with the memory system.

## Quiz Quality

- No ambiguous options.
- Explanations are required.
- Hints should guide without giving away the answer instantly.
- Mistake keys should be present where possible.
- Difficulty and source reference must be tagged.

## Review Status

Use:

- `draft` for incomplete material.
- `needs_review` for seeded or generated-but-not-reviewed material.
- `verified` after academic review.
- `published` only when ready for students.

Stage 8 Class 11 Unit 1 content is seeded as original NCERT-aligned material with `needs_review` quality status.
