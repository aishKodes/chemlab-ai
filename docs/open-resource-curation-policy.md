# Chemlab Open Resource Curation Policy

Chemlab may link to external simulations, videos, worksheets, and open educational resources, but public pages must not copy copyrighted material into Chemlab content.

## Allowed Use

- Prefer Chemlab original explanations and simulations.
- Use NCERT only as a source backbone and reference, not as copied public text.
- Prefer public-domain or open-license resources where reuse terms are clear.
- When unsure, use `link_only` and open the external resource in a new tab.
- Show source, author/source name, license, and attribution whenever an external item is displayed.

## Required Fields For External Resources

An external resource must have:

- `source_url`
- `license_type`
- `attribution_text`
- author or source name
- `usage_type`: `link_only`, `embed_allowed`, or `adapted`
- `accuracy_review_status`
- admin notes
- license reviewed confirmation before publishing

## Publishing Rule

Do not publish an external resource unless:

- the source URL is present
- license type is present
- attribution text is present
- an admin has reviewed the license
- quality status is reviewed or verified

## Public Display

- Show attribution clearly.
- Do not call external resources Chemlab originals.
- Open in a new tab unless the license explicitly allows embedding.
- If embedding is allowed, still show source and attribution.
- For live demos, unreviewed PhET, Mol*, Jmol/JSmol, video, worksheet, or external visualization candidates must stay in admin review only. Do not publish or iframe them until `license_reviewed` is true and accuracy review is at least reviewed.

## NCERT-Aligned Content

NCERT-aligned Chemlab content should be original student-facing explanation, activities, simulations, and practice. Store source references for review, but do not paste full textbook sections into public pages.
